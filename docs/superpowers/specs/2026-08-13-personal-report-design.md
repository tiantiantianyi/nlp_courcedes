## 3. 报告结构

### 3.4 第三节：个人技术工作

每小节遵循“问题 -- 本人修改 -- 验证 -- 结论边界”的同一结构，并给出关键文件路径，

## 5. LaTeX 实现方案

采用 `ctexart` 文档类和 XeLaTeX 中文编译，正文使用 `geometry`、`booktabs`、
`longtable`、`graphicx`、`hyperref`、`xcolor`、`enumitem` 和 `microtype`。参考文献使用
BibTeX 文件；若只引用少量论文和项目文档，正文保持简洁引用，附录列出代码提交证据。

输出目录：

```text
docs/personal_report/
├── 张添翼_U202315231_个人报告.tex
├── references.bib
└── 张添翼_U202315231_个人报告.pdf
```

源文件和最终 PDF 均提交 Git。LaTeX 辅助文件 `.aux/.log/.out/.toc/.bbl/.blg/.fls/.fdb_latexmk`
不提交。

## 6. 编译环境

当前系统没有检测到 `xelatex`、`latexmk` 或 `tectonic`。优先安装系统 XeLaTeX 中文最小
组合：`texlive-xetex`、`texlive-lang-chinese`、`texlive-latex-extra`、`latexmk`。
如果系统包管理器不可用，则使用可写用户目录中的 Tectonic，并调整文档为其可获得的
中文字体和宏包组合。

安装后依次执行：

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error \
  docs/personal_report/张添翼_U202315231_个人报告.tex
pdfinfo docs/personal_report/张添翼_U202315231_个人报告.pdf
pdftotext docs/personal_report/张添翼_U202315231_个人报告.pdf -
```

通过条件：编译退出码为 0，PDF 约 5--7 页，姓名学号正确，中文可提取，无未定义引用，
无越界表格或致命字体警告。
